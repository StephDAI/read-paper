# Prototype sources (historical)

`plugin.host.js` and `plugin.client.js` are the original **dynamic Cordis
plugin** sources — the process-local prototype this package grew out of.
Dynamic plugins do not survive Harness restarts; the production plugin lives
in `lib/` and is installed as a profile bundle (see the main README).

Kept for reference only; they are not part of the shipped package.
